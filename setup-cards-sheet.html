📋 Setup Cards Sheet

Configura la fulla de Google Sheets per emmagatzemar les dades de les fitxes

📌 Què és la fulla "Cards"?
És una fulla de Google Sheets que emmagatzema les dades de les 15 fitxes. En crear-la, es pre-poblen les 15 files amb els IDs de fitxa i foto. Cada vegada que un usuari adopti o editi una fitxa, les dades es desaran aquí.

1Estructura de la Fulla "Cards"

La fulla tindrà les següents columnes:

Col. Nom del Camp Descripció
A Card ID ID de la fitxa (ex: 01FC05) - pre-poblat
B Photo ID ID de la foto (ex: FotosCavet00005) - pre-poblat
C Common Name Nom comú de l'espècie
D Scientific Name Nom científic de l'espècie
E Comment Comentaris sobre la fitxa
F Foto Author Autor de la foto
G Card Author Usuari que ha adoptat la fitxa
H Last Modified Data de la darrera modificació

2Crear la Fulla Automàticament

Utilitza el teu Google Apps Script URL per crear la fulla automàticament amb totes les columnes.

3Configuració Manual (Alternativa)

Si prefereixes crear la fulla manualment:

  1. Obre el teu Google Sheet
  2. Crea una nova fulla anomenada exactament "Cards"
  3. A la fila 1, afegeix les capçaleres segons la taula de dalt
  4. Opcional: Formata la fila de capçaleres amb color de fons i text en negreta
